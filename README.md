# Task_1
This repository contains three data cleaning projects completed using Python and Pandas. The objective of these projects is to transform raw datasets into clean, analysis-ready datasets by handling missing values, correcting data types, removing duplicates, and standardizing data formats.

Datasets Included

1. Marketing Campaign Dataset
Files:
marketing_campaign.csv (Raw Dataset),
cleaned_marketing_campaign.csv (Cleaned Dataset), and
marketing_campaign_cleaning.py (Python Script).

Cleaning Tasks Performed:
Removed unnecessary columns,
Handled missing values,
Corrected data types,
Standardized column formats, and
Removed duplicate records.

2. Walmart Sales Dataset
Files:
walmart_sales.csv (Raw Dataset),
cleaned_walmart_sales.csv (Cleaned Dataset), and
walmart_sales_cleaning.py (Python Script).

Cleaning Tasks Performed:
Checked and handled missing values,
Converted date columns to proper datetime format,
Removed duplicate entries,
Corrected inconsistent data formats, and
Prepared dataset for analysis and visualization.

3. Netflix Dataset
Files:
netflix_titles.csv (Raw Dataset),
cleaned_netflix_titles.csv (Cleaned Dataset), and
netflix_cleaning.py (Python Script).

Cleaning Tasks Performed:
Handled missing values,
Converted date fields to datetime format,
Standardized text fields,
Removed duplicates, and
Cleaned categorical data.

Technologies Used
Python,
Pandas,
NumPy,
VS Code, and
Spreadsheets.

Learning Outcomes
Through these projects, I gained hands-on experience in:
Data cleaning and preprocessing,
